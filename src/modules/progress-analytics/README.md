# progress-analytics

SPEC `docs/SPEC.md` §5.6 · checklist group 7.8.

Real-time progress dashboard for managers (scoped to the projects they manage),
per-assignee workload, weekly/monthly overview reports (throughput, on-time
rate, return count, ads totals, cost-weighted average ROAS, top items),
period-over-period comparison, and CSV/Excel export.

All figures are computed from `statusHistory` and `adsMetrics`; no rollup table
at this stage (SPEC §6.7).
